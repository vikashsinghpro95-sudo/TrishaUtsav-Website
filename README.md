# 🪔 TrishaUtsav — Festive & Cultural E-Commerce Platform

TrishaUtsav is a modern, high-performance, mobile-first E-Commerce web application for festive handcrafted sweets, artisanal brass diyas, ethnic wear, and celebration hampers across India.

## 🚀 Features
- **Chip-Based Occasions & Categories Filter**: Instant AJAX product filtering with horizontal momentum scroll chips.
- **⚡ Direct "Buy Now" Checkout**: Skip cart and proceed directly to dynamic checkout.
- **Mobile-First App Experience**: Optimized mobile top hero, sticky action bars, dynamic banners, and fast loading.
- **Admin Control Panel**: Dynamic homepage layout management, product CRUD, settings, and newsletter manager.
- **Razorpay & COD Integration**: Full online payment gateway & Cash on Delivery support.

## 🛠️ Technology Stack
- **Backend**: PHP (MVC Router, PDO Database layer, RESTful JSON APIs)
- **Frontend**: Vanilla JS (ES6+), HTML5, Tailwind CSS / Custom CSS
- **Database**: MySQL

## 🔧 Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/vikashsinghpro95-sudo/TrishaUtsav-Website.git
   ```
2. Copy environment file and configure database credentials:
   ```bash
   cp .env.example .env
   ```
3. Install composer dependencies (if any):
   ```bash
   composer install
   ```
4. Run locally with built-in PHP server:
   ```bash
   php -S localhost:8000 -t public
   ```
